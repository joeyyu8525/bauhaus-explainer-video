# 画面与互动手册

写剧本数据前必读。它回答两个问题：**这段内容该用什么画面**，**角色该做什么**。

## 一、按内容选画面

先判断这段台词属于哪一类，再选主视觉。同一类内容有多种做法时，相邻章节要换着用。

| 内容类型 | 主视觉（首选 / 备选） | 角色怎么互动 |
|---|---|---|
| **提问、开场** | 大字问题 + 问卷或窗口 `card` / 大字 + 一个问号积木 | 小鱼用 `think` 或 `talk` 走进画面；小人从卡片后探出来 |
| **一个关键数字** | 超大数字 + 色块（`text` 的 `size` 1.2 以上，配合 `stamp`）/ 单根很高的柱子 | 小鱼 `point` 指向数字；小人跳上柱顶 |
| **两三个数值对比** | 柱状图 `box` / 并排的两个点阵 | 小人跳上"不对"的那根柱子并 `shake`；对的那根做 `pulse` |
| **分布、比例、"往中间靠"** | **两组 `crowd` 对比**，颜色比例按真实数据设 | 小人站在自己代表的那一组旁边；小鱼站在两组之间 `shrug` |
| **样本、人群、"很多人"** | 大 `crowd` 点阵 | 小人从点阵里走出来，代表"其中一个" |
| **方法、流程、步骤** | `rect` 色带连成路线 + 每步一个积木或卡片 | 小人**沿着路线一路走过去**，每到一步对应台词 |
| **分层、几个原因、几条结论** | 叠起来的分层色带（三条宽 `rect`，红黄蓝，依次 `wipe`）/ 金字塔（三个尺寸递减的 `box` 叠高） | 小鱼依次 `point`，每层出现时 `pulse` |
| **对立、反差、"但是"** | 左右分栏：左边一组元素、右边一组元素，中间一个大"≠"或"VS" | 两个小人各站一边，互相看；被否定的一方 `shrink` |
| **引用原话、金句** | 引语卡：`card` 上叠大字，旁边加出处小字 | 小鱼 `sign` 举牌，用 `say` 气泡说出要点 |
| **原因、机制、"为什么"** | 因果链：积木 → 箭头（细长的 `rect`）→ 积木 | 小鱼 `think`；小人沿因果链走一遍 |
| **局限、警告、风险** | 红色大字 + `fx` 的 `shake` 或 `flash` / 倒下的积木（`box` 加 `rot`） | 小人 `wobble` 或 `shake`；小鱼 `shrug` |
| **总结** | 编号列表（01/02/03 色块条依次出现） | 小鱼 `sign` 举牌加气泡；两个小人 `nod` 或 `bounce` |

## 二、互动的写法原则

1. **动作对上台词**：先看时间轴里那句话从几秒开始说，动作就放在那一秒，或者提前 0.2 秒。
2. **动作要有含义**：
   - 跳上柱子：表示"我就是这个数"或"看这里"。
   - shake：表示"不对、害怕"。
   - nod：表示"同意"。
   - shrug：表示"意外、没那么简单"。
   - 不要无缘无故让角色走来走去。
3. **一次只让一个角色抢戏**：同一时刻最多一个角色在做明显动作，其他角色站着或轻微动作。
4. **角色要跟着内容换场**：换章时，角色要走到、跳到或瞬移（`move: 'pop'`）到新内容旁边，不能留在原地等镜头带过去。
5. **气泡要少而精**：每章最多 1–2 个，每个不超过 12 个字，用来说出比字幕更口语化的反应，比如"我只生成了 10.5%……""先验证，再使用"。

## 三、每章自查（写完一章就对一遍）

- [ ] 主视觉和上一章不同
- [ ] 至少 2 种非文字元素
- [ ] 至少 2 次角色互动，且都对上了台词时间戳
- [ ] 小鱼出现，并且换过姿势
- [ ] 会被角色锚定的元素都写了 `id`
- [ ] 数字与原文一致，柱子和点阵比例真实
- [ ] 卡片容器宽度/深度是否经公式核算，文字未超出黑边
- [ ] 角色是否避开了多行文字与卡片正前方（无重叠遮挡）
- [ ] 画面元素与气泡出现时间严格与台词同步，无抢跑
- [ ] `--check` 输出 OK

## 四、常见错误与避坑铁律

| 错误 | 正确做法 |
|---|---|
| 两个小人整片固定在 x≈4 和 x≈2.4，只跟着镜头往下挪 | 每章都用 `to` 锚定到当章的元素 |
| 每章都是"一堆字 + 两三根柱子" | 按第一节的表格换着用主视觉 |
| 分布类数据也画成柱子 | 用两组 `crowd` 对比 |
| 空卡片占半屏，里面什么都没有 | 卡片上必须有内容（`rect` 文字行、小积木、数字），否则不要用卡片 |
| 长英文小标题冲出右边 | 用 `size: 0.26`，或者缩短文字；以 `--check` 结果为准 |
| **卡片内文字戳穿右侧黑边** | 按 `(字数 × size × 0.85) + 0.8` 严算卡片宽度 `w`，留出足量安全 margin |
| **小人站在卡片正前方挡住字** | 严禁 `side: 'front'`，一律改到卡片左右翼（`side: 'left'` 或 `'right'`） |
| **台词还没念，画面元素和气泡先出来** | 元素与气泡 `t` 严禁抢跑，应滞后于对应台词 0.1~0.2 秒 |
| **长篇多行总结同屏互相打架** | 拆分为两个 Stage（Part 1 对谈争论 -> Part 2 总结清场推进）分阶段呈现 |
| **同屏出现两个完全一样的概念/气泡** | 静态检查静帧，删除冗余词汇，确保视听信息增量清晰 |
