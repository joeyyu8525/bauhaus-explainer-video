# 剧本数据与元素速查

本文以 `src/engine.js` 为准。坐标单位是世界单位：x 向右，z 向观众（画面下方），y 向上。

## 顶层结构

```js
export default {
  fps: 22,
  duration: 480,                 // 秒，略长于配音
  brand: '睿塔科技 | 周小鱼',     // 右上角署名
  theme: { ... },                // 可选，覆盖调色板（见下）
  dark: false,                   // 深色底时设 true（HUD 自动反色）
  shadow: 0.2,                   // 地面阴影浓度
  chapters: [ { t, zh, en, meta, color } ],
  subs:     [ { t, end, who, text } ],
  camera:   [ { t, x, z, dist, yaw, pitch } ],
  actors:   [ { kind, keys: [ { t, x, z } ], out, face, unit } ],
  elements: [ ... ],
};
```

## 调色板

颜色字段可以写名字，也可以写 `#hex`：

| 名字 | 值 | 用途 |
|---|---|---|
| bg | #efe9d8 | 米白底 |
| ink | #141414 | 正文黑 |
| red | #d32a2a | 强调、结论 |
| yellow | #f2b61b | 疑问、提示（上面的字自动用黑色） |
| blue | #1f4faa | 概念、名词 |
| grey | #8f8a7d | 次要线条 |
| paper | #f7f3e6 | 卡片面、色块上的字 |

## 章节卡 `chapters`

| 字段 | 说明 |
|---|---|
| `t` | 从这个时间开始显示 |
| `zh` | 中文大标题，2–4 个字最好 |
| `en` | 英文小标题，会自动转成大写 |
| `meta` | 出处一行，例如 `Argyle et al. · 2023` |
| `color` | 标题下短横线的颜色 |

## 字幕 `subs`

| 字段 | 说明 |
|---|---|
| `t` / `end` | 起止秒数 |
| `who` | `'a'` 蓝圆点（小鱼）、`'b'` 红方块（阿硅）、`'c'` 黄三角（备用） |
| `text` | 字幕文字 |

用 `subsFrom(LINES)`（见 `examples/sample_base.js`）可以从逐句时间轴自动切成短句。

## 镜头 `camera`

| 字段 | 说明 | 范例值 |
|---|---|---|
| `x`, `z` | 注视点 | 跟着内容走 |
| `dist` | 距离，越大画面越远 | 24 |
| `yaw` | 水平角度，负数表示地面向左倾 | -15 |
| `pitch` | 俯角，越大越接近俯视 | 50 |

- 关键帧之间用 inOutCubic 缓动，另外叠加一点轻微漂移，画面不会完全静止。
- 两个关键帧的值相同，镜头就停住。

## 角色 `actors`

### 三种角色

| `kind` | 说明 | 专属字段 |
|---|---|---|
| `'avatar'` | 主讲人 Q 版形象，是一张始终面向镜头的竖立图片 | `poses`：`{ 姿势名: 图片URL }`；`h`：身高，默认 2.4，建议 2.4–2.6；`defaultPose` |
| `'human'` | 红衣体素小人 | `unit`：体素大小，默认 0.075 |
| `'bot'` | 蓝色体素机器人 | 同上 |

周小鱼的姿势图在 `assets/avatar/`：

| 姿势 | 适用场景 |
|---|---|
| `stand` | 开场、倾听 |
| `talk` | 讲解 |
| `point` | 指向左侧的数据或结论 |
| `think` | 提问、转折、"为什么" |
| `shrug` | 意外、无奈、"没那么简单" |
| `sign` | 举牌，适合金句和结论，配合 `say` 气泡 |

```js
const A = (n) => new URL(`../assets/avatar/pose_${n}.png`, import.meta.url).href;
{ kind: 'avatar', h: 2.5, defaultPose: 'stand',
  poses: { stand: A('stand'), talk: A('talk'), point: A('point'), think: A('think'), shrug: A('shrug'), sign: A('sign') },
  keys: [...], pose: [...], acts: [...], say: [...] }
```

### 通用字段

| 字段 | 说明 |
|---|---|
| `keys` | 移动路线，见下。第一个 `t` 是登场时间（弹出） |
| `move` | 默认移动方式：`'walk'` 蹦跳着走（默认）、`'jump'` 抛物线跳、`'pop'` 原地缩小后在目标点弹出（瞬移） |
| `pose` | 仅 avatar 使用：`[{ t, p: '姿势名', flip }]`，到时间就换姿势；`flip: true` 表示左右镜像，例如让 point 指向右边 |
| `acts` | 一次性动作：`[{ t, do, dur, h, n, amt }]` |
| `say` | 气泡台词：`[{ t, end, text, color }]`，`color` 可选 `'red'`、`'yellow'`、`'blue'`，不填为白底 |
| `out` | 消失时间 |
| `face` | 体素小人静止时的朝向（角度） |
| `name` | 质检报告里显示的名字，可选 |

### keys：两种写法

**锚定写法（推荐）**：

```js
{ t: 4.6, to: 'b_gpt', side: 'right', gap: 1.6 }
```

| 字段 | 说明 |
|---|---|
| `to` | 元素的 `id` |
| `side` | `'left'`、`'right'`、`'front'`（靠镜头一侧）、`'behind'`、`'top'`（站到柱顶）、`'center'` |
| `gap` | 与元素边缘的距离，默认 0.55 |
| `dx`, `dz` | 在锚点基础上再微调 |
| `move` | 走到这一点用的方式，覆盖默认 |
| `face` | 到达后的朝向 |

> [!CAUTION]
> **多行文本与卡片（card）站位绝对禁忌**：
> 凡是内部承载了文字、rect 或多行内容的卡片，**绝对禁止角色使用 `side: 'front'`**！因为体素小人和 avatar 具有一定身高和宽度，站在正面会直接把卡片上的文字、数字遮挡得严严实实。
> - **正确做法**：一律锚定在卡片左翼（`side: 'left'`）或右翼（`side: 'right'`），并设置 `gap: 0.6 ~ 1.0`。
> - 若想表现小人探头，使用 `side: 'behind'` 配合 `dz: -0.2` 从卡片顶部边缘探出。

**坐标写法**：`{ t, x, z, y }`。

角色在两个 key 之间移动。两个 key 的位置相同，角色就停在原地。

### acts 动作

| `do` | 效果 | 可调参数 |
|---|---|---|
| `jump` | 原地跳 | `h` 高度 |
| `bounce` | 连跳，表示开心、兴奋 | `n` 次数，`h` |
| `shake` | 左右抖，表示害怕、否定 | |
| `nod` | 点头，表示同意 | `n` |
| `spin` | 转一圈，表示得意 | |
| `wobble` | 摇晃，表示晕、站不稳 | |
| `grow` | 变大，表示自信 | `amt` |
| `shrink` | 变小，表示心虚 | `amt` |

`dur` 是动作时长，默认 0.6 秒，bounce 默认 1.2 秒。

### say 气泡规范与生命周期

```js
say: [{ t: 6.4, end: 8.8, text: '我只生成了 10.5%……', color: 'blue' }]
```

- **严禁抢跑**：气泡 `t` 必须晚于或等于台词发音时间（`t >= line.t + 0.1`）。台词未说、气泡先出属于严重穿帮。
- **字数上限**：不超过 14 个汉字。超长文字转为地面 text 或多句气泡。
- **及时收回**：`end` 必须在角色开始下一段大位移前结束，避免气泡漂移出界或与下一动作打架。

## 元素 `elements`

所有元素的通用字段：

| 字段 | 说明 |
|---|---|
| `id` | 元素名字，角色锚定和质检报告都用它。**会和角色互动的元素必须写 `id`** |
| `type` | 元素类型 |
| `fx` | 出场后的强调特效：`[{ t, do, dur, amt }]`，`do` 可选 `'pulse'` 脉冲放大、`'squash'` 被压扁（角色跳上来时用）、`'shake'` 抖动、`'flash'` 闪烁 |
| `at` | 出现时间 |
| `out` | 消失时间（0.4 秒淡出），可选 |
| `x`, `z` | 位置 |
| `y` | 高度，可选 |
| `rot` | 绕竖轴旋转的角度 |
| `dur` | 入场动画时长，默认 0.5 |
| `anim` | 覆盖默认入场动画 |
| `layer` | 平面元素的叠放层级 |
| `opacity` | 不透明度 |

入场动画：

| `anim` | 效果 | 默认用于 |
|---|---|---|
| `rise` | 淡入并上滑 | text |
| `stamp` | 从大缩到正常，像盖章 | 强调文字时手动指定 |
| `wipe` | 从左向右展开 | rect |
| `pop` | 弹出 | box、cyl、prism、card、image |
| `grow` | 从地面长高 | 柱状图手动指定 |
| `drop` | 从空中掉落弹跳 | |

### text：平铺在地面上的文字

```js
{ type: 'text', at: 2.7, x: -3.3, z: -1.3, size: 1.05, anim: 'stamp',
  text: [{ t: '能不能', gap: 0.08 }, { t: '不找人', bg: 'red' }] }
```

| 字段 | 说明 |
|---|---|
| `text` | 字符串，或分段数组 `[{ t, bg, color, gap, strike }]`：`bg` 是色块底；`gap` 是与下一段的间距（按字号的倍数）；`strike` 是删除线颜色 |
| `size` | 字高，单位是世界单位 |
| `font` | `'zh'` 思源黑体（默认），`'en'` Archivo Black（粗英文、数字），`'enw'` Archivo 宽体（小标题，配合 `track` 使用） |
| `weight` | 字重，默认 900 |
| `track` | 字距（按字号的倍数），小标题用 0.28 左右 |
| `align` | `'left'`（默认，x 为左端）、`'center'`、`'right'` |
| `color` | 整行文字颜色 |

常用字号：

| 用途 | `size` |
|---|---|
| 大标题 | 1.0–1.45 |
| 正文句 | 0.5–0.8 |
| 数字 | 0.5 |
| 英文小标题 | 0.26–0.34 |

### rect：地面上的色带或线条

```js
{ type: 'rect', at: 1.4, x: -2.95, z: 0.5, y: 0.09, w: 2.6, d: 0.2, color: 'ink' }
```

`x` 是左端，`w` 是长度，`d` 是粗细。

### box / cyl / prism：立体积木

```js
{ type: 'box', at: 18.2, x: -2.3, z: 17.6, w: 1, d: 1, h: 1.8, color: 'blue', anim: 'grow', dur: 0.7 }
```

| 类型 | 尺寸字段 |
|---|---|
| `box` | `w`、`d`、`h` |
| `cyl` | `r`、`h` |
| `prism`（三棱柱） | `r`、`h` |

做柱状图时：
- 高度要与数值成比例。
- 年份、数值标签放在柱子前方：标签 z 约等于柱子 z + 1.1 / + 1.7，用 `align: 'center'`。

### card：平放的窗口或问卷卡片

```js
{ type: 'card', at: 1.0, x: -1.4, z: 1.0, w: 3.8, d: 2.5, bar: 0.34 }
```

| 字段 | 说明 |
|---|---|
| `bar` | 顶部黑条的高度 |
| `frame` | 边框颜色 |
| `color` | 卡面颜色 |

卡片上的"文字行"用 `rect` 叠上去（`y: 0.09`），小圆点用很扁的 `cyl`。

> [!TIP]
> **卡片容器尺寸计算公式（严防文字戳破边框）**：
> 卡片宽度 `w` 和深度 `d` 绝不能随意估算，必须根据承载的内容计算：
> 1. **宽度 `w`**：必须大于内部最长单行文本长度 + 双侧安全边距。
>    - 估算公式：`w >= (最长文本字数 × size × 0.85) + 0.8`。例如 18 个英文字符配 `size: 0.38`，长度约 5.8，卡片宽度 `w` 至少要设为 `6.8 ~ 7.2`。
> 2. **深度 `d`**：必须容纳标题黑条 `bar`、所有内容行、行间距以及底部留白。
>    - 估算公式：`d >= bar + (行数 × 行高) + ((行数 - 1) × 行距) + 0.6`。
> 3. **卡片内文字定位**：内部文字的 x 必须从卡片左端向右留出内边距（`card.x - card.w / 2 + 0.4`），z 从顶条下方开始排。严禁文字跨越卡片右边缘！

### crowd：人群点阵（表示样本、被试）

```js
{ type: 'crowd', at: 13.2, x: -0.55, z: 10.4, cols: 11, rows: 3, gap: 0.5, s: 0.3, h: 0.22,
  span: 1.2, shuffle: true, mix: [['red', 0.4], ['blue', 0.4], ['ink', 0.2]] }
```

| 字段 | 说明 |
|---|---|
| `mix` | 颜色和比例 |
| `shuffle` | 打乱位置，并随机依次弹出 |
| `span` | 全部弹出所用的秒数 |
| `shape: 'box'` | 改成方块 |
| `seed` | 随机种子 |

可以用不同的 `mix` 对比"真人分布"和"AI 分布"。比例要用原文数字。

### image：图片

```js
{ type: 'image', at: 3, x: 3.8, z: 2, h: 2.4, src: '<file URL>', stand: true }
```

- `stand: true` 表示竖立并始终面向镜头，会投射阴影，适合放透明底的人物立绘。
- 不加 `stand` 则平铺在地面上。
- `src` 用 file URL，例如 `pathToFileURL(...)`，或 `file:///D:/...`。
